# Médias RBS

Dépose ici les fichiers réels (photos, vidéos, logo). Une fois un fichier
ajouté, dis-moi juste son nom et je le branche dans le code — pas besoin
de toucher au reste du projet.

## Où déposer quoi

- `logo/` — logo RBS (SVG de préférence, sinon PNG fond transparent haute résolution)
  - ex: `logo/rbs-logo.svg`, `logo/rbs-logo-white.svg` (variante pour fond sombre)
- `video/` — vidéos (hero plein écran, teasers soirées, clips)
  - ex: `video/hero.mp4` (fond de la home), `video/session-01.mp4`
  - format recommandé : `.mp4` (H.264), compressé, idéalement < 15-20 Mo pour le hero
- `photos/` — photos (produits, soirées, portraits artistes)
  - ex: `photos/hoodie-01.jpg`, `photos/live-heartful-night-01.jpg`
  - format recommandé : `.jpg` ou `.webp`, déjà redimensionné (pas de RAW 20 Mo)

## Fichiers volumineux

Si un fichier dépasse ~150-200 Mo (vidéo longue, ProRes...), ne le mets pas
ici : envoie un lien de téléchargement (Drive, WeTransfer, etc.) et je le
récupère et compresse moi-même.
